# Kaiku 1.0.0

Kaiku is now signed with a Developer ID certificate and notarized by Apple, so Gatekeeper no longer blocks the first launch. No more right clicking the app or clearing the quarantine flag from Terminal: download the DMG, drag Kaiku to Applications, and open it.

Kaiku also checks for updates on its own from now on. It asks once, the second time you open it, whether it should check automatically; you can change that later in Settings, or trigger a check any time from the menu bar icon's "Check for Updates…" item. Updates are downloaded and verified with Sparkle before installing.

The app remains a universal binary for both Apple Silicon and Intel Macs, whisper-cli included.

If you have found Kaiku useful, there is now a "Buy Me a Coffee…" item in the menu and a discreet link in Settings.

If you are still on mc.Rofone, the one time migration to Kaiku described in the README still applies: your settings, API keys, webhook headers and recordings folder move over automatically, nothing is deleted, and macOS will ask for permissions again since Kaiku is a new app to the system.

Since versions before 1.0.0 have no updater, this is the last release you will need to install manually. Download the DMG from the release page, replace the old Kaiku in Applications, and every release after this one will offer to update itself.
