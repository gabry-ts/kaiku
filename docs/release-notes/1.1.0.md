# Kaiku 1.1.0

Kaiku now shares one design with Tuuli, Kiito, Mittari and Kello. The popover, the Library, Settings, onboarding and About are built from the same components as the other apps, so buttons, switches, cards and the settings window look and behave the same everywhere.

The popover leads with the red recording button, with the switch to mute all microphones right below it, then your recent calls. While recording, the card shows the timer, the input level and the Pause, Bookmark and Stop buttons. A new footer has Recordings, Settings, a ⋯ menu for updates and Buy Me a Coffee, and Quit.

Settings uses the shared window with a sidebar and can now be resized. The updates switch moved to About.

Recording and transcription work exactly as before, and no permissions need to be granted again.
