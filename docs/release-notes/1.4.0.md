# Kaiku 1.4.0

Kaiku can now transcribe your calls with the speech recognizer built into macOS 26. Pick "Apple (on this Mac)" in Settings > Transcription: it is free, nothing leaves your Mac, there is no API key and no whisper model to manage. It downloads the model for your language once, from the same page. It doesn't detect the language by itself, so with the language on automatic it uses your Mac's.

Live transcription has three more engines next to Apple's: whisper.cpp, which transcribes the call in chunks about ten seconds behind, and OpenAI and ElevenLabs, which stream the audio to their realtime services with the API keys you already saved. With the two cloud engines the audio of both sides of the call is sent to the provider during the call and billed by them; Settings says so when you pick one. Apple stays the default.
