Kaiku 1.7.0

Can't make a call? Send the meeting bot. It joins Google Meet, Microsoft Teams, Webex and FaceTime links from the menu, now or when a meeting from your calendar starts, and it runs on your Mac in a hidden Google Chrome, so nothing goes through anyone's cloud. Give it a name, a picture and a chat message in Settings, or write a different message each time you send it. It records the call, leaves when everyone else has, and the headphones button lets you listen in. Nothing joins a call unless you send it.

Recordings shorter than 30 seconds, by length or by speech, now go to the Trash as soon as they stop, before anything is spent transcribing them. Choose the limit in Settings › Recording.

Agents can have any audio or video file transcribed with the new transcribe_file tool of the MCP server, using the provider you picked. Nothing is kept unless they ask to save it, and it stays off until you allow it in Settings › Integrations.

Speech models downloaded for the macOS speech recognizer are now reserved, so macOS no longer removes them between transcriptions.
