# Kaiku 1.0.2

Calendar access works again. Like the microphone in 1.0.1, the signed build was missing the permission macOS requires to read calendars, so the Allow button did nothing and Kaiku could not name recordings after the event happening now. After updating, Kaiku asks for calendar access when you click Allow.

This release also fixes the release notes shown in the update window, which failed to load for 1.0.1.
