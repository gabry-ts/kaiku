# Kaiku 1.0.3

You can now choose what starts a recording. Every detected call has a source: the app it runs in, or for a web call the service in the browser window, so WhatsApp Web, Google Meet and Teams on the web are no longer all "Google Chrome". The same service counts as one source in its app and on the web.

The new Sources tab in Settings lists every source with Always, Never or New. Call apps like Zoom and Teams record as before. Messaging apps with voice notes, like WhatsApp and Telegram, start as New: Kaiku records the first time and asks whether to always record them, and choosing Never stops the recording and deletes it. You can add any other app or website, and remove any source you don't want.

Without a calendar event, auto-detected recordings are now named after the call window, such as the Teams meeting name, the FaceTime contact or the WhatsApp chat.

The Library shows where each call came from, lets you change it, and filters by source as well as by tag.

Telling web calls apart needs the Accessibility permission, which Kaiku asks for once after updating. It only reads the title of the window in front.
