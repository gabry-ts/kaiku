# Kaiku 1.0.1

This release fixes microphone access in 1.0.0. The signed build was missing the permission macOS requires to use the microphone, so the system denied it silently: Kaiku never asked for access and never appeared under System Settings > Privacy & Security > Microphone. After updating, Kaiku asks for microphone access the first time it records, as it should.

The menu bar footer also fits on one line again: "All Recordings" is now simply "Recordings".
