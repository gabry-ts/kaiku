# Kaiku 1.2.0

You can now choose what Kaiku's popover shows. The new Popover page in Settings lists its sections: drag them into the order you like and switch off the ones you don't need. The record button always stays on top; the mute switch, the transcription status, recovered calls and recent calls are yours to arrange.

You can also pick how many recent calls the popover lists: 3, 5 or 8.
